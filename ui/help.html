Overview

WatchTower is a modular attack-surface reconnaissance pipeline. Every stage is a standalone Python script that reads JSON from database/<program>/ and writes JSON back to the same place. No external database, no migrations — just files on disk.

Modules can be run individually, chained in watch.sh, or driven by the Flask dashboard in app.py. All output is also accessible via the REST API under /api/*.

Design philosophy: each script does one thing, fails gracefully, and its state is visible as a plain JSON file. You can cat, jq, or grep anything.

Quick Start

1. Sync programs

Define your targets in programs/*.json, then sync to the database:

bash 
python3 programs/watch_sync_programs.py

2. Run the full pipeline

bash 
bash watch.sh

This runs all enabled stages in order. Each run creates a new log under database/<program>/log/. A lock file (run.lock) prevents concurrent runs.

3. Open the dashboard

bash 
python3 app.py
# → http://localhost:5000

Pipeline

Each stage is independent. You can run any stage manually.

# Stage Script Reads Writes

4 Wordlist utils/watch_wordlist_all.py enum-output/ wordlist/
5 DNS dns/watch_ns_all.py enum-output/ dns/lives.json
6 Filter IPs dns/watch_filter_privates_ip_all.py dns/lives.json dns/lives.json

Modules

Enumeration core

Passive subdomain discovery via 13 sources: subfinder, CRT.sh, Chaos, Wayback, GAU, CRTmon, crt.name, AgniOps, Assetfinder, waymore, Findomain, github-subdomains, and AbuseIPDB (reverse-IP). Results merged with per-source attribution.

bash 
cd enumeration
python3 watch_enum_all.py

Output: database/<p>/enum-output/all-subdomains.json

DNS Resolution core

Wildcard test runs first (3 random probes). Then dnsx resolves every subdomain to IPs. Reserved / private IPs are filtered out afterward.

bash 
cd dns
python3 wildcard/watch_wildcard_ns_test_all.py
python3 watch_ns_all.py
python3 watch_filter_privates_ip_all.py

Output: database/<p>/dns/lives.json

Note: if a domain has wildcard DNS, brute-force stages should use the *_wildcard_all.py variants which apply IP filtering.

HTTP Probing core

Runs httpx with TLS, favicon, and tech detection. Stores status, title, technologies, and resolved IPs.

bash 
cd http
python3 watch_httpx_all.py

Output: database/<p>/http/lives-http.json

CDN / WAF Detection new

Uses cdncheck (ProjectDiscovery) to classify each IP as CDN, Cloud, WAF, or direct. Auto-updates once per process, falls back to built-in ranges if GitHub is unreachable.

bash 
cd cdn
python3 watch_cdn_all.py

Output: database/<p>/cdn/lives-cdn.json

Port Scan core

Non-CDN hosts get a SYN scan over ~22 common ports. CDN hosts get a CONNECT scan over only the ports their CDN actually forwards to origin (Cloudflare 12, Akamai 19, CloudFront 80+443+1024-65535, Fastly/Bunny 2).

bash 
cd portscan
python3 watch_portscan_all.py --fresh

Output: database/<p>/portscan/lives-portscan.json

Virtual Hosts new

For non-CDN, public-IP hosts only: baseline with a random Host header, then fuzz with static wordlist + all known subdomains. Already-tested (host, ip) pairs are skipped unless --force.

bash 
cd vhost
python3 watch_vhost_all.py
# adhoc test against a specific IP:
python3 watch_vhost.py 1.2.3.4 --limit 100 --workers 10

Output: database/<p>/vhost/lives-vhost.json

WHOIS / RDAP core

Queries RDAP (the modern replacement for WHOIS) for each domain and IP. Handles 404, 429, 5xx gracefully. Never re-queries a target unless --force.

bash 
cd whois
python3 watch_whois_all.py

Output: database/<p>/whois/lives-whois.json

Screenshots core

Playwright (Chromium) captures a full-page PNG for each HTTP service. Falls back to HTTP if HTTPS fails. Skips already-captured screenshots unless --force.

bash 
cd screenshot
python3 watch_screenshot_all.py --fresh

Output: database/<p>/screenshots/<host>.png

Nuclei attack

Runs the Nuclei scanner against all live HTTP URLs. Only findings with severity critical, high, medium, or low are kept — info is dropped to reduce noise.

bash 
cd attack/nuclei
python3 nuclei_url_maker.py --all
python3 watch_nuclei_all.py --fresh

Output: database/<p>/nuclei/nuclei-result.json

REST API

All /api/* routes return JSON. HTML routes are at the root. An after_request guard ensures nothing under /api ever returns HTML.

EndpointDescription
GET /api/statsGlobal + per-program statistics
GET /api/programsAll programs with scopes
GET /api/program/<name>Single program details
GET /api/subdomainsAll subdomains (add ?fresh=1)
GET /api/subdomains/<name>Subdomains for one program
GET /api/lives/<name>Live hosts for one program
GET /api/http/<name>HTTP services
GET /api/cdn/<name>CDN/Cloud/WAF detection
GET /api/portscan/<name>Open ports per host
GET /api/vhost/<name>Discovered virtual hosts
GET /api/nuclei/<name>Nuclei findings
GET /api/screenshots/<name>Screenshot file list
GET /api/bruteforce/<name>Brute-only subdomains

Troubleshooting

Pipeline fails silently

Check database/<program>/log/logN.txt for the latest run. Each stage's stdout and stderr are captured there.

CDN detection says "Direct" for everything

Likely cdncheck failed to update and is missing ranges. Run manually:

bash 
cdncheck -up
cdncheck -i 1.1.1.1 -resp

Screenshots not captured

Playwright may not be installed. Fix:

bash 
pip install playwright
playwright install chromium

Nuclei times out

Large URL lists can take hours. Use --fresh to only test new URLs, or lower the rate limit in attack/nuclei/watch_nuclei.py.

Tip: every module has a --fresh flag (or a done-file) so re-runs skip what's already been processed. You can safely run watch.sh as often as you want.
